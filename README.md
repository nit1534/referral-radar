Referral Radar
Job applications on LinkedIn have a near-zero success rate without a referral. This tool helps job seekers identify the right people to contact for referrals by analyzing real LinkedIn job posting data.
The tool takes a dataset of 123,849 LinkedIn job postings, filters by job role, and ranks companies by a custom referral score based on number of openings, application competition ratio, and salary data. It also generates a personalized cold message template for the top company.
Built with: Python, Pandas
How to run:
pip install pandas openpyxl
python referral_radar.py
Output: A ranked list of target companies exported to Excel, with a cold outreach message ready to send.
